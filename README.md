# منصة إدارة الجمعيات الذكية (Smart Gameya Platform)

نظام متكامل لإدارة جمعيات التوفير والادخار (ROSCA) بشكل رقمي مرن، مصمم خصيصاً لتلبية احتياجات منظمي الجمعيات (الأدمن) والمشتركين، مع دعم الأسهم المقسمة وإدارة عدة جمعيات في وقت واحد، والتواصل عبر واتساب بدون رسوم إضافية.

---

## 🚀 المميزات الرئيسية
1. **إدارة متعددة الجمعيات:** يتيح للمنظم (الأدمن) إنشاء وإدارة أكثر من جمعية في نفس الوقت بكل تفاصيلها وقوائمها.
2. **الأسهم المرنة والمقسمة (Flexible Shares):** سهم الجمعية الواحد يمكن تقسيمه على عدة أفراد بنسب ومبالغ مختلفة، مع تحديد شهور القبض لكل فرد بدون أي تضارب.
3. **الحماية الرياضية للحسابات:** نظام آلي يتحقق من تطابق إجماليات الأقساط والمبالغ لضمان عدم وجود عجز أو زيادة.
4. **تواصل مجاني عبر واتساب:** تكامل ذكي مع روابط واتساب المباشرة (`wa.me`) لإرسال التذكيرات الفردية والجماعية بضغطة زر.
5. **تصدير البيانات:** إمكانية حفظ وتصدير بيانات الجمعية بجميع الصيغ (JSON, Markdown, CSV) للرجوع إليها في أي وقت.
6. **واجهة عصرية وسريعة:** تصميم متجاوب (Mobile-First) يدعم اللغة العربية بالكامل (RTL).
