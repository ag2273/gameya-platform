# متطلبات النظام وقواعد التشغيل (System Requirements & Business Rules)

هذا المستند يحدد متطلبات النظام الوظيفية وغير الوظيفية، بالإضافة إلى القواعد الحسابية والرياضية المنظمة لعمل "الجمعيات الذكية".

---

## 1. المتطلبات الوظيفية (Functional Requirements)

### أ. إدارة الجمعيات (Multi-Gameya Management)
- **إنشاء جمعية جديدة:** للأدمن صلاحية إنشاء عدد غير محدود من الجمعيات، بحيث تحتوي كل جمعية على:
  - اسم الجمعية (مثلاً: جمعية العيد، جمعية الشغل).
  - إجمالي قيمة السهم (مثلاً: 10,000 جنيه).
  - قيمة القسط الشهري الأساسي (مثلاً: 1,000 جنيه).
  - عدد الشهور / الأعضاء (مثلاً: 10 شهور).
  - تاريخ بداية ونهاية الجمعية.
- **تعديل / إغلاق جمعية:** إمكانية تعديل تفاصيل الجمعية طالما لم تبدأ، أو أرشفة الجمعية بعد اكتمالها.

### ب. نظام الأسهم المقسمة (Flexible Shared Slots)
- **سهم مستقل:** شخص واحد يمتلك السهم كاملاً، يدفع القسط كاملاً ويقبض في شهر محدد.
- **سهم مشترك (مقسم):** عدة أفراد يشتركون في سهم واحد (مثلاً: 3 أشخاص في سهم قيمته 1000 جنيه).
  - يتم تحديد نسبة ومبلغ كل فرد (مثلاً: أحمد 400، محمد 300، سارة 300).
  - يتم تحديد شهر/شهور القبض لكل فرد أو ائتلاف بناءً على اتفاقهم.
- **قاعدة التحقق الرياضي (Math Validation):** لا يسمح النظام بحفظ السهم المشترك إلا إذا كان مجموع أقساط الأفراد يساوي تماماً قيمة قسط السهم الأساسي دون أي زيادة أو نقص.

### ج. تتبع الأقساط والدفع (Installment Tracking)
- لكل شهر جدول مصفوفة يوضح حالة كل عضو:
  - **تم الدفع (Paid - ✔)**
  - **متبقي (Pending - ❌)**
- حساب إجمالي الصندوق الشهري تلقائياً ومعرفة المبلغ المحصل والمتوقع.

### د. التكامل مع واتساب (WhatsApp Integration)
- توليد روابط واتساب مباشرة (`wa.me/[phone]?text=...`) مجهزة برسائل جاهزة:
  - تذكير فردي بقسط الشهر.
  - إشعار بموعد القبض.
  - تقرير حالة الجمعية للأدمن.

### هـ. تصدير البيانات (Export Engine)
- تصدير بيانات الجمعية والأعضاء والأقساط بصيغ:
  - JSON (للنسخ الاحتياطي والبرمجة).
  - Markdown (للتقارير والعرض).
  - CSV (لفتحه في Excel).

---

## 2. المتطلبات غير الوظيفية (Non-Functional Requirements)
- **السرعة والأداء:** واجهة خفيفة وسريعة (Mobile-First) تعمل بكفاءة على جميع الهواتف الذكية.
- **حفظ البيانات:** استخدام قاعدة بيانات SQLite محلية تضمن استمرارية البيانات وعدم فقدانها عند إعادة تشغيل التطبيق.
- **الأمان:** فصل الصلاحيات بين لوحة الأدمن وبوابة المشتركين.
