# المعمارية التقنية والهندسة البرمجية (System Architecture)

يوضح هذا المستند المكونات التقنية، هيكل قاعدة البيانات، وطريقة عمل محرك التصدير والتكامل في منصة "الجمعيات الذكية".

---

## 1. التقنيات المستخدمة (Tech Stack)
- **الخلفية (Backend):** Python مع إطار عمل **FastAPI** (سريع، آمن، ويدعم توثيق API التلقائي).
- **قاعدة البيانات (Database):** **SQLite** (خفيفة، محلية، ولا تتطلب إعدادات معقدة للخادم).
- **الواجهة الأمامية (Frontend):** HTML5, Tailwind CSS (تصميم عهري ومتجاوب Mobile-First)، مع JavaScript للتفاعل الديناميكي.
- **التواصل الخارجي:** روابط واتساب المباشرة (`https://wa.me/...`) لضمان مجانية وسهولة الإرسال دون الحاجة لبوابات دفع أو APIs مدفوعة.

---

## 2. هيكلة قاعدة البيانات (Database Schema - SQLite)

يتكون النظام من 3 جداول أساسية مرتبطة بعلاقات سليمة:

### أ. جدول الجمعيات (`gameyas`)
- `id` (Primary Key)
- `name` (اسم الجمعية)
- `total_amount` (إجمالي مبلغ السهم)
- `monthly_installment` (قسط السهم الشهري)
- `total_months` (عدد الشهور / الأعضاء)
- `created_at` (تاريخ الإنشاء)

### ب. جدول الأعضاء والحصص (`members_shares`)
- `id` (Primary Key)
- `gameya_id` (Foreign Key -> gameyas.id)
- `share_group_id` (معرف السهم المشترك، لربط الشركاء في نفس السهم)
- `member_name` (اسم المشترك)
- `phone` (رقم الهاتف للواتساب)
- `share_ratio` (نسبة المشاركة أو المبلغ المدفوع، مثلاً 500 من 1000)
- `payout_month` (شهر القبض المحدد)

### ج. جدول متابعة الأقساط (`installments`)
- `id` (Primary Key)
- `gameya_id` (Foreign Key -> gameyas.id)
- `member_id` (Foreign Key -> members_shares.id)
- `month_number` (رقم الشهر، مثلاً شهر 1، شهر 2...)
- `status` (حالة الدفع: `pending` أو `paid`)
- `updated_at` (تاريخ اخر تحديث)

---

## 3. محرك تصدير البيانات (Export Engine)
يدعم النظام تصدير حالة الجمعية بالكامل إلى 3 صيغ رئيسية يتم توليدها ديناميكياً:
1. **JSON Export:** لتخزين كامل هيكل الجمعية والأعضاء والأقساط كملف نصي منظم.
2. **Markdown Export:** لإنشاء تقرير مرئي جميل يمكن مشاركته في الملاحظات أو عبر منصات التوثيق.
3. **CSV Export:** لتحويل جدول الأقساط والأعضاء إلى ملف جدول بيانات متوافق مع برامج Excel و Google Sheets.
